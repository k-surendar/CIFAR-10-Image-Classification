# CIFAR-10 Image Classification Using CNN

## Project Overview
This project focuses on image classification using the CIFAR-10 dataset. A baseline deep learning model was trained and compared with an improved experiment to evaluate classification performance.

## Dataset
The CIFAR-10 dataset contains 60,000 color images across 10 classes, including airplanes, cars, birds, cats, dogs, and ships.

## Technologies Used
- Python
- TensorFlow / Keras
- Convolutional Neural Networks (CNN)
- Google Colab
- Matplotlib

## Experiments and Results

| Model | Test Accuracy |
|---|---:|
| Baseline Model | 75.23% |
| Experiment 3 | 78.57% |

**Improvement:** 3.34 percentage points over the baseline.

## Workflow
1. Load the CIFAR-10 dataset.
2. Preprocess and normalize the images.
3. Build and train the baseline model.
4. Experiment with model improvements.
5. Compare test accuracy and loss.
6. Evaluate the final model.

## How to Run
1. Open the notebook in Google Colab.
2. Run the cells from top to bottom.
3. Review the model evaluation and comparison results.
